# Contributing

TxEquibot is currently a documentation-and-prototype project. Useful contributions include unclear requirements, missing execution failure cases (especially for one-sided fills across two venues), documentation corrections and feedback on the proposed user journey.

Before proposing a major feature, explain the user problem, expected behavior, dependencies and how it would be validated. Keep the TxFlow-primary hedged-cycle scope distinct from later strategies and venues.

Use official references for API claims and include the review date. Clearly label hypotheses, planned capabilities and observed behavior. Do not submit credentials, private account exports, signed trading payloads or unsupported performance claims.

There is no executable trading application or test command yet. Documentation changes should preserve working relative links and consistent project status. Implementation contributions will need meaningful tests for trading lifecycle, the edge gate and account isolation when code exists.
